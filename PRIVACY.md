# Privacy Policy — Fet Notification Filter

Last updated: July 29, 2026

## Summary

This browser extension does not collect, store, transmit or sell any
personal data. There are no analytics, no tracking, no external servers.

## What the extension does

The extension runs only on fetlife.com. It reads the notification elements
on the user's own notifications page locally in the browser in order to
classify them by type (e.g. loves, comments, mentions) and hides the types
the user chose to hide. All processing happens inside the browser; no page
content ever leaves the device.

## What is stored

The only data the extension stores are the user's own filter settings:
which notification types to hide and whether filtering is enabled. These
settings are saved via the browser's built-in extension storage
(`storage.sync`), which may sync them across the user's own browser
profile through the browser vendor's account sync (Mozilla or Google),
subject to that vendor's privacy policy. The extension itself has no
access to any server.

## What is NOT collected

- No browsing history, page content or notification content
- No personal or account information
- No usage statistics or telemetry
- No cookies, fingerprinting or identifiers

## Third parties

No data is shared with third parties, because no data is collected.
The extension makes no network requests of its own.

## Changes

Changes to this policy will be published in this repository. Since the
extension collects nothing, changes are expected to be editorial only.
